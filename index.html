Traffic needs a key
This build has no TomTom API key baked in — the deployed version gets one injected from a GitHub Actions secret at deploy time. For local testing, run localStorage.gew_tomtom_key = 'YOUR_KEY' in the console and hit Refresh. A key is free at my.tomtom.com (freemium: 50,000 tile and 2,500 non-tile requests a day).
